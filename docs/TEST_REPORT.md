# ტესტირების შედეგები

## რა გაკეთდა

- კოდის სტატიკური გადახედვა ხელით: ტიპები, სიგნალების დაკავშირება, ავტოლოდების თანმიმდევრობა, Input Action-ები.
- ლოგიკური გამოთვლა დონის გავლადობაზე (ხტომის სიმაღლე ≈ 92 px, საჭირო მაქსიმუმი 48 px საფეხური; ხტომის სიგრძე ≈ 175 px, მაქსიმალური ხვრელი 144 px).

| GDScript-ის სინტაქსის შემოწმება ძრავით | იგივე მიზეზი — შეცდომები შეიძლება დარჩეს |

## მოსალოდნელი პრობლემები პირველი გაშვებისას (შესამოწმებელი)

1. **GDScript-ის პატარა შეცდომები** (ტიპები, გაფრთხილებები) — პირველი გახსნისას Output/Debugger პანელში გამოჩნდება.
2. **ქართული გლიფები** — თუ ჩანს კვადრატები, ჩაამატე Noto Sans Georgian ფონტი.
3. **განათება**: `CanvasModulate` + `PointLight2D` ერთად — თუ ძალიან ბნელია, შეცვალე `Level._modulate.color` ან `light.energy`.
4. **მართვის შეგრძნება**: ჯოისტიკის მგრძნობელობა, მკვდარი ზონა (`DEADZONE`), ღილაკების ზომა — ტესტი რეალურ ტელეფონზე.
5. **Safe area**: `get_safe_insets` შეიძლება არასწორი იყოს `expand` stretch-ზე — გადაამოწმე ამოჭრილი ეკრანით.
6. **`export_presets.cfg`** — პარამეტრების სახელები Godot-ის ვერსიით განსხვავდება; Export ფანჯარაში გადახედე.
7. **პაუზა ფონზე გადასვლისას** — `NOTIFICATION_APPLICATION_PAUSED` რეალურ Android-ზე უნდა დადასტურდეს.
